🔬 Microarchitecture & Physical Tapeout
Full digital architecture mapped to SkyWater 130nm standard cells with OpenROAD.
Synthesizable Sub-Blocks Verilog HDL (5 Modules)
1. 12-Bit ADC Stream Receiver spf_trend_engine.v
Accepts 12-bit streaming voltage samples (0–4095 mV) synchronized with adc_valid strobe.
2. 4-Tap Moving-Average Noise Filter spf_trend_engine.v
Eliminates high-frequency inductive switching ripple: V_filt = (tap0 + tap1 + tap2 + tap3) / 4.
3. Negative Derivative Engine (dV/dt) spf_slope_calc.v
Calculates drop velocity: ΔV = V[t-1] - V[t]. Catches severed wires and broken batteries pre-emptively.
4. Two-Tier Threshold Comparators spf_fsm.v
Tier 1 triggers early warning (pfi_warn_o) at 2.85V; Tier 2 triggers emergency shutdown (shdn_req_o) at 2.70V.
5. Autonomous 6-State Power FSM spf_fsm.v
Pure digital state machine: IDLE → NORMAL → SAG_DETECT → EARLY_WARN → CRITICAL → RECOVER.

📑 Memory-Mapped Control & Status Registers (CSR)
Programmable 8-bit bus interface for threshold configuration and sticky interrupt handling.
Offset Register Name Bits Reset Type Description & Functionality
0x00 CTRL_REG [7:0] 0x01 R/W Bit 0: Engine Enable; Bit 1: Slope Enable; Bit 2: Filter Bypass; Bit 3: Interrupt Mask.
0x01 STATUS_REG [7:0] 0x01 RO Bit 0: pfi_warn_o state; Bit 1: shdn_req_o state; Bits [4:2]: Current 6-State FSM code.
0x02 V_WARN_THRESH [7:0] 0xB6 R/W Tier 1 Early Warning Threshold (High byte: 0xB6 = 2,850 mV). Default: 2.85V trigger.
0x03 V_CRIT_THRESH [7:0] 0xA8 R/W Tier 2 Emergency Panic Threshold (High byte: 0xA8 = 2,700 mV). Default: 2.70V trigger.
0x04 SLOPE_THRESH [7:0] 0x32 R/W Maximum negative derivative threshold: 0x32 = 50 mV drop between consecutive samples.
0x05 HYST_THRESH [7:0] 0x96 R/W Recovery Hysteresis margin (0x96 = 150 mV). Rail must climb past 3,000 mV to clear warning.
0x06 INT_CLEAR_REG [7:0] 0x00 WO Write 0x01 to clear sticky PFI interrupt; Write 0x02 to reset emergency shutdown request.
🏆 Novelty & Benchmark Comparison
How the Smart Power-Failure Predictor outclasses legacy Brownout Detectors (BOD).

✕ Legacy Brownout Detectors (BOD)

  • ✕
    Purely Reactive: Triggers only after voltage has already collapsed below 2.5V, leaving exactly 0 μs for CPU registers to save state.
  • ✕
    False Alarms on Ripple: Inductive load switching ripples (10–30 mV) trigger false resets and crash operating systems.
  • ✕
    No Derivative Sensing: Completely blind to negative slope drop velocity (dV/dt); cannot detect severed wires until it is too late.
  • ✕
    High Analog Quiescent Power: Requires continuous power-hungry analog reference zener/bandgap circuits.

✓ Smart Power-Failure Predictor ASIC

  • ✓
    Proactive Early Warning: Asserts pfi_warn_o 10 to 50+ ms in advance at 2.85V, allowing complete Flash/EEPROM cache flushes.
  • ✓
    4-Tap FIR Moving Filter: Cancels high-frequency switching ripples, preventing nuisance resets under heavy motor/RF pulses.
  • ✓
    Fast Negative Slope Engine: Detects severe drop velocities (ΔV ≥ 50 mV/sample) immediately, catching disconnects even at 3.15V.
  • ✓
    100% Pure Software Flow: Synthesized into 1,296 standard cells using open-source Yosys & OpenROAD on SkyWater 130nm.

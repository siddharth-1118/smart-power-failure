🔬 Microarchitecture & Physical Tapeout
Full digital architecture mapped to SkyWater 130nm standard cells with OpenROAD.
Synthesizable Sub-Blocks Verilog HDL (5 Modules)
1. 12-Bit ADC Stream Receiver spf_trend_engine.v
Accepts 12-bit streaming voltage samples (0–4095 mV) synchronized with adc_valid strobe.
2. 4-Tap Moving-Average Noise Filter spf_trend_engine.v
Eliminates high-frequency inductive switching ripple: V_filt = (tap0 + tap1 + tap2 + tap3) / 4.
3. Negative Derivative Engine (dV/dt) spf_slope_calc.v
Calculates drop velocity: ΔV = V[t-1] - V[t]. Catches severed wires and broken batteries pre-emptively.
4. Two-Tier Threshold Comparators spf_fsm.v
Tier 1 triggers early warning (pfi_warn_o) at 2.90V; Tier 2 triggers emergency shutdown (shdn_req_o) at 2.60V.
5. Autonomous 6-State Power FSM spf_fsm.v
States: RESET → NORMAL → SAG_DETECT → EARLY_WARNING → PANIC_SHUTDOWN → RECOVERY (with hysteresis).
6. Memory-Mapped CSR Bank spf_reg_bank.v
Runtime threshold configuration and sticky interrupt clearing over host MCU bus.

💡 Why This ASIC Is Novel
How our predictive architecture solves the fundamental flaws of legacy brownout detectors.

✕ Traditional Brownout Detectors (BOD)

  • ✕ Purely Reactive: Only fires after VDD has already collapsed below CPU minimum (< 2.5V).
  • ✕ Zero Advance Time: MCU has 0 μs left to save data; in-flight Flash/EEPROM writes become permanently corrupt.
  • ✕ Noise Susceptible: High-frequency inductive motor/radio switching ripple causes false panic resets.
  • ✕ Fixed Silicon Limits: Hardcoded thresholds cannot adapt to battery aging or cold-weather sag.
  • ✕ Contact Chatter: Bounces rapidly between reset and run states as power rail fluctuates.

✓ Our Smart Power-Failure Predictor ASIC

  • ✓ Predictive Advance Notice: Delivers Early Warning Interrupt 10 to 50 ms before collapse.
  • ✓ Dual-Engine Filtering: 4-tap FIR filter rejects 30 mV switching ripple with zero false alarms.
  • ✓ Derivative Rate-of-Fall (dV/dt): Catches severed wires instantly, before voltage even reaches 2.90V!
  • ✓ Runtime Tunability: Memory-mapped CSRs allow dynamic threshold adjustment via host MCU bus.
  • ✓ Chatter-Free Recovery: 6-state FSM with 100 mV multi-cycle hysteresis prevents contact oscillation.
